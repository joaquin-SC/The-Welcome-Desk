# Welcome Desk — FIFA World Cup 2026 Visitor Resource

A multilingual visitor information platform for international FIFA World Cup 2026 visitors. Website + WhatsApp chatbot + native app wrapper.

**Status:** Pre-build / Specification phase

## What this is

One website. Eleven city pages. A WhatsApp chatbot that responds in the visitor's language. Everything an international FIFA visitor needs — Know Your Rights information, consular contacts, emergency numbers, fan zone maps, transit guides — in one place, on their phone, the moment they land.

## Architecture

```
Visitor on phone
    |
    ├── Scans QR → WelcomeTo2026.org/[city] → React PWA (Lovable) → Supabase DB
    |
    ├── Taps WhatsApp → WhatsApp Business API → Supabase Edge Function
    |                                                |
    |                                                ├── Language detection (LLM)
    |                                                ├── Query FAQ/KYR database
    |                                                ├── Generate response (LLM API)
    |                                                └── Can't answer → Escalate to live operator
    |
    └── Voice command → Native app (Phase 2) → Emergency call + location + WhatsApp alert
```

## Tech stack

- **Frontend:** React (generated by Lovable.dev), Tailwind CSS
- **Backend:** Supabase (PostgreSQL, Edge Functions, Auth for admin)
- **Chatbot:** WhatsApp Business API + Supabase Edge Function + LLM API (OpenAI or Anthropic)
- **Native wrapper (Phase 2):** Capacitor (iOS + Android)
- **Deployment:** Lovable hosting (Phase 1), App Store + Google Play (Phase 2)

## Project context

This platform is one of six concepts in the Mayors for America FIFA World Cup 2026 strategy package, developed by Conexión Public Engagement. The Welcome Desk serves as the digital infrastructure layer that the other five concepts (Host City Pledge, Game Day Protocol, Hosting Premium, 11 Cities 1 Summer, Longer Tables) connect to.
